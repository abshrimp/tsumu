# スクリプトエディタのブロック構成と型

## データ型

利用者向けの型は **「値」と「リスト」** の2種類とする。

- **値**：文字列、数値、真偽値、`null`。例えば `"123"`、`123`、`false`。
- **リスト**：配列、辞書、入れ子のJSONデータ。例えば `["a","b"]`、`{"name":"田中"}`。

内部のJavaScript/JSON型は維持し、表示名を統一するために配列を辞書に変換したり、数値を文字列に変換したりしない。数値演算では数値として解釈できる文字列を利用できるが、IDやキーに含まれる先頭ゼロは、元のデータを変更しない限り保持する。

値を直接入力すると、`12`、`true`、`null`、`[1,2]`、`{"a":1}` などの明確なJSONリテラルを解釈する。数値に見える文字列などは `"0012"` と二重引用符で囲む。単独の `{変数}` は元の内部型を維持し、通常の文字と変数を混ぜた入力は文字列になる。

## ブロックと条件

スクリプトは「きっかけ → 動作」の順に構成する。きっかけはクリック、ホバー開始、ホバー終了、値の変更、ページ読み込み、画面に入ったときの6種類。動作は表示・移動・入力・データ・変数・リスト・ストレージ・制御のカテゴリから選択する。

「値を加工する」の候補は次の **12操作** のみとする。

| 分類 | 加工 |
|---|---|
| 取得 | リストから項目を取り出す |
| 情報 | リストの項目数を数える |
| 計算・変換 | 数値を計算する、表示用の文字にする、JSON文字列に変換する、JSON文字列を読み取る |
| 文字列 | 分割する、リストを文字列につなぐ、置き換える |
| リスト | 並べ替える、要素を末尾に追加する |
| 補完 | 値が存在しないとき別の値を使う |

条件の判定は「もし」、リストの選択・集計は「ループ」と「リストへの代入」を組み合わせて構成する。

条件には「と同じ」「含む」「で始まる」「で終わる」「より大きい」「以上」「より小さい」「以下」「いずれかと同じ」「空」「項目が存在する」を使える。比較は `true` と `"true"`、`1` と `"1"` を区別する。数値の大小だけは数値として比較できる文字列も受け付ける。

**「リストに含む」** は直下の各項目の **値** を探索する。**「項目が存在する」** は自分自身が持つ **キー** を調べる。例えば `{"apple":100}` は `100` を含み、キー `"apple"` が存在するが、値 `"apple"` を含まない。リスト同士の等価判定はキーと値を再帰的に比較する。どちらの検索も入れ子の値を無制限にたどらない。

条件は「である／でない」で反転でき、「かつ／または」で連結できる。「かつ」を先に評価してから「または」を評価する。未設定の条件を誤って真と判定しない。

## リストの基本操作とループ

辞書の並べ替え結果は元のキーを失わないよう、`{ "キー": 元のキー, "値": 元の値 }` の項目を並べた配列として返す。配列を並べ替えた場合は配列の要素の形を保持する。元のリストは変更しない。

「空のリストを変数にする」「リストのキーに値を入れる」「リストに要素を追加する」を組み合わせて、新しいリストを作る。配列ではキーを空欄にすると末尾追加になる。辞書ではキーを指定して追加・更新する。変数として保持する値は非破壊で更新し、危険なプロパティ書き込み、極端に大きなインデックスや処理件数を制限する。

「リストの項目ごとにくり返す」は配列・辞書の両方で動作し、`null`、値、入れ子リストも処理する。ループの内側では次の値を使える。

| 参照 | 内容 |
|---|---|
| `{ループ.値}` | 現在の項目の値 |
| `{ループ.キー}` | 現在の項目のキー（文字列） |
| `{ループ.順番}` | 0から始まる処理順 |
| `{ループ.外側.値}` | 入れ子のときの外側の項目 |

「ループを終了する」は最も内側のループだけを抜ける。ループの後の処理は続行する。有限回の繰り返しと「ずっとくり返す」の両方に使用できる。ループ外では実行できないようにする。プレビュー・サーバーでの配信前処理・生成コードで同じ結果になることを検証する。

例えば、辞書のキーと値の組を一覧にしたい場合は、空リストを作り、辞書の各項目を繰り返し、`{ループ.キー}` と `{ループ.値}` を持つ行を追加する。条件に合う最初の1件を探す場合は、条件成立時に結果を保存し、その場でループを終了する。

## リスト表示とデータ保存

画面上のリストを「絞り込む」「並べ替える」「絞り込みを解除する」のは、変数の中身を変更することとは別の操作である。表示の絞り込みでは「かつ／または」「である／でない」を使える。

リスト内の値の数を数える場合、配列は通常の長さ、辞書は直接のキー数を返す。JSONを読んだ場合は配列と辞書の保存形式を保持する。ストレージに保存したTsumuの値についても、内部型を読み込み時に再現できるようにする。

データ取得のURL・メソッド・ヘッダー・本文と取得結果は、元のJSONデータの意味を保つ。値とリストの共通仕様は変数候補、スクリプト、ページ表示、エクスポート結果に適用する。

## 実行と検証

ページを開いたときのスクリプトは、データ取得の後に純粋な演算や条件分岐・有限ループをサーバー側で実行できる。画面操作・待機・ブラウザストレージなどに依存する処理はブラウザで実行する。サーバー・エディタ・生成コードの計算結果を一致させる。

値が存在しないときは後続の補完を実行できるようにする。一方、計算不能・不正な型・無限大・ゼロ除算・実行上限超過などは適切なエラーとして扱い、誤った暗黙変換を行わない。配列・辞書の項目参照や変数名の難読化によって、意図しないプロトタイプ参照やコード実行が起きないようにする。
