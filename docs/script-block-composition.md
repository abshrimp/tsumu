# スクリプトのブロック構成

「加工」を別の大型モーダルで組み立てず、**1ブロック = 1つの処理**としてスクリプトのワークスペースで縦に連結する。

通常パレットは **きっかけ6種類・動作16種類** とし、次のカテゴリにまとめる。

- 表示操作・画面遷移・スクロール・入力欄の値と有効状態
- データ取得、変数への代入、純粋な値の加工、ブラウザへの保存と読み出し
- クリップボードへのコピー、リスト表示の操作
- 待機、条件分岐、指定回数の繰り返し、リスト各要素への繰り返し

## 値を加工する

「変数に値を入れる」→「値を加工する」→「値を加工する」のように上下へ配置する。後ろの加工ブロックを直前の出力ブロックの下へ置くと、直前の出力変数名を入力元と出力先に自動設定する。同じ変数名を繰り返し使えば途中の変数を増やさず、異なる出力先を指定すれば途中結果を残せる。

値の加工は、項目の取得・存在判定、数値演算・比較、文字列の分割・連結・置換、JSON変換、リストの検索・絞り込み・各項目の変換・並べ替え・追加・削除、値がないときの補完などを選択できる。

比較値やリストへの設定値は「文字列／数値／真偽値／null」から選ぶ。「文字列」は同じ入力欄に通常の文字と `{変数}` を混在でき、階層付きの変数候補も使える。値がないときの代替値・区切り文字・文字列置換・項目名なども同様で、`こんにちは、{name}さん` のように書ける。`{変数}` だけの場合は数値・配列・オブジェクトなどの元の型を保持する（文字列専用の操作では文字列への変換や型確認を行う）。文字としての `{` は `\\{` と書く。数値の計算では右辺に数値または変数を指定できる。数値として解釈できる10進文字列は数値へ変換してから演算するが、比較演算では元の型を区別する。

条件指定は「もし」「リストの絞り込み」「値を加工する」の比較・検索・絞り込みで共通の演算子を用いる。「と同じ」「を含む」「で始まる」「で終わる」「より大きい」「以上」「より小さい」「以下」「のいずれかと同じ」「空」から選び、各条件に「である／でない」を指定できる。「値を加工する」では「かつ／または」で条件を何件でも追加できる。複数条件は「かつ」を先にまとめ、その組を「または」で接続する。各条件の文字列には `{変数}` を埋め込める。比較時の型規則はブロックの種類に応じて維持する。

リストへの追加は末尾に1件追加、値による削除は厳密に一致する値の全件削除、位置による削除は先頭を0・末尾を-1とした1件削除となる。リストの要素数は最大10,000件までとする。これらは元のリストを直接変更せず、新しいリストを返す。型が合わない場合はエラーとし、出力変数を書き換えない。

「要素ごとにくり返す」はリストの各要素を順番に処理する。「ページを開いたとき」の直下でも、内部がデータ専用の操作（変数への代入・値の加工・変数条件の「もし」・有限回の繰り返し・入れ子の要素繰り返し）だけなら、データ取得の後にサーバー側で実行できる。プレビューにも同じ計算を反映する。画面操作・ストレージ操作・待機などブラウザ専用処理を含む場合は、サーバーでは実行しない。各要素の項目を参照して計算し、別のリストへ追加するなどの処理はできるが、元のリストの該当要素への暗黙の書き戻しは行わない。

## リスト表示を操作する

画面上のリストの「絞り込み」「並べ替え」「絞り込み解除」は1つのブロックのモードで表す。**値の加工によって新しいリストを作る**ことと、**既に表示しているリストの表示状態を変える**ことは別の操作となる。

## 実行とデータ形式

スクリプトの手順は従来どおり配列で、順番に実行する。型として持つのは現在のブロックだけであり、過去の専用ブロックや編集モーダルの形式は保持しない。値の操作は共通の評価器を利用し、エディタ・サーバー・公開サイトで同じ規則を適用する。

未変換の過去データを読み込んだ場合の動作は保証しない。必要な場合は、新しい編集画面へ読み込ませる**前に、別途提供するオフライン変換プログラムでコピーを変換**する。
